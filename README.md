# DA558A-Lab-2 Personal Portfolio

## Setup

1. Clone or download the project.
2. Open the project folder in a web browser or Visual Studio Code.
3. Start the page by opening `index.html`.

## Project Structure

- `index.html` – the page structure and contact form
- `styles/style.css` – layout and styling
- `javascript/contact.js` – form validation and interaction
- `assets/` – images used on the page

## Contact Form

The contact form validates:

- first name and last name
- email address
- selected subject
- a message with at least 20 characters

The phone number is optional. When all required fields are valid, a personalized
confirmation message is displayed.
